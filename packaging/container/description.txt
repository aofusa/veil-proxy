veil: a high-performance reverse proxy and web server (HTTP/1.1, HTTP/2, HTTP/3, gRPC, Proxy-Wasm). Try it: docker run --rm -p 8080:8080 ghcr.io/aofusa/veil, then open http://localhost:8080/ (the built-in page has a quickstart). Your files: -v $PWD/site:/var/www:ro. Your config: -v $PWD/config.toml:/etc/veil/conf.d/config.toml:ro. Guide: https://github.com/aofusa/veil-proxy/blob/main/docs/guide/container.md

# B-280: 1 ファイルを指す File ルートで起動時に「静的ルートを登録できない」警告が出る

**状態: 修正済み（v0.10.1）**

## 出典

統合試験（`type = "File"`・`path` がファイル）のログで見つけた（実機で確認）。

## 事象

静的配信のパス解決（dirfd 相対の `openat2`。F-153）のルートの登録は、ルートの `path` をディレクトリとして開く。1 ファイルを指すルートは
`ENOTDIR` になり、`warn!` で失敗として記録していた。配信は従来の経路で正しく行われるので、利用者には誤った警告だけが見える。

## 修正（v0.10.1）

- `ENOTDIR` は「ファイルなので登録しない」として `debug!` にする（`src/cache/resolve.rs`）。他の失敗は今までどおり警告する。

# B-161: 起動に失敗しても終了コードが 0 になる

**状態: 完了（feat/distribution-tickets、2026-10-23。F-247 の作業で発見）**

## 現象

設定の読み込み・検証の失敗、リスナーの bind の失敗などで起動できなかったとき、`veil` はエラーを出して
**終了コード 0** で終わっていた。

- 例: 存在しない File のルート、壊れた TOML。
- **影響:** systemd の `Restart=on-failure`、rc.d、コンテナのオーケストレーター、スクリプトが失敗に気づけない。
  パッケージの既定の起動（F-251）で、起動できない設定を「成功」と扱ってしまう。

## 原因

`entry::run_server` は起動の途中のエラーで `return` するだけで、`veil::run()`（`src/main.rs` の `main`）は
そのまま正常に戻っていた。

## 修正

- 全リスナー・ワーカーの起動を終えた時点で `STARTUP_COMPLETED` を立てる。
- バイナリの `run()` は、`run_server` から戻ったときにそれが立っていなければ、終了コード 1 で終える。
  - ライブラリ（`veil::serve`）の戻り方は変えない。
- F-247 の設定ファイルが無いときのエラーも、終了コード 1。
- 確かめたこと: 存在しない File のルート、壊れた TOML、設定ファイル無しのどれも、終了コード 1。

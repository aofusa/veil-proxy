# B-147: HTTP/3 のバッファ経路の要求本文に上限が無かった

**状態: 完了（feat/v080-release、2026-10-18。F-236 の再走査の F4）**

## 症状

`Decision::Buffer` に分類したストリーム（プロキシでないルート・ルートの無い要求・Wasm・`buffering = full`・HTTP/1.1 の上流への
gRPC・メトリクス）は、受け取った DATA を全部 `stream_bodies` へ溜めていた。quiche から読むたびにフロー制御のクレジットが
増えるので、FIN の無い本文で無限に溜められた。

## 修正

溜める途中で上限（B-146 と同じ）を超えたら、読むのをやめてストリームを H3_EXCESSIVE_LOAD で両方向とも閉じ、溜めた本文を捨てる。

## 関連

F-236、B-146。

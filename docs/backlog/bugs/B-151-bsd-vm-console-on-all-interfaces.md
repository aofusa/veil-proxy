# B-151: 試験用の BSD の VM のシリアルコンソール・QMP・SSH を全アドレスで待っていた

**状態: 完了（feat/v080-release、2026-10-18。F-236 の再走査の F10）**

## 症状

`tools/qemu/bsd-vm.sh` は、シリアルコンソール（telnet）・QMP・SSH の転送を native のモードでも 0.0.0.0 で待ち、Docker のモードは
全アドレスへ公開していた。root の既定のパスワードは `veil` なので、VM の起動中は同じネットワークの誰でもコンソールから root に
なれた。コメントは「127.0.0.1 だけ」と書いていた。

## 修正

native のモードは 127.0.0.1 で待ち（`GUEST_BIND`）、Docker のモードは `-p 127.0.0.1:...` で公開する。既定のパスワードは既存の
VM のコンソールの手順のため残す（ホストの利用者しか届かない）。コメントを直した。

# B-145: WebSocket のハンドシェイクの後ろのバイトを、上流のアップグレードの前に送っていた

**状態: 完了（feat/v080-release、2026-10-18。F-236 の再走査の F6）**

## 症状

WebSocket の要求は、ヘッダの後ろに読み取り済みのバイトを全部ハンドシェイクの後ろに付けて送っていた。上流がアップグレード
しない（WebSocket でないエンドポイント）と、上流はそれを veil が照合・検査していない次の HTTP の要求として処理し、veil はその
応答もクライアントへ返した。

## 修正

ハンドシェイクと一緒に送るのは、要求の本文（Content-Length の分）だけにする。その後ろのバイトは、上流が `101` を返したときだけ
送り、返さなければ捨てる。
